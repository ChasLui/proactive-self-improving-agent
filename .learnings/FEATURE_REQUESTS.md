# Feature Requests

记录用户反复需要、但当前 Grok 配置、工具或技能体系没有覆盖的通用能力。

**Areas**: coding | tools | docs | config | workflow | research  
**Statuses**: pending | resolved | promoted_to_skill

## Entry Template

```markdown
## [FEAT-YYYYMMDD-XXX] capability-name

**Priority**: low | medium | high | critical
**Status**: pending | resolved | promoted_to_skill
**Area**: coding | tools | docs | config | workflow | research

### 需要的能力
用户想完成什么。

### 场景
为什么现有工具链不足，未来哪里会复用。

### 建议实现
应该扩展哪个配置、hook、command、agent 或 skill。

### 元数据
- Frequency: first_time | recurring
- See Also:
- Promoted-To:

```
