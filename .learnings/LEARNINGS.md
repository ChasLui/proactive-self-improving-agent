# Learnings (Fallback Mode)

> 本文件仅在 omp memory backend 不可用时使用。若 `memory.backend` 配置为 `mnemopi` 或 `hindsight`，请使用 `retain` / `recall` / `reflect` 工具代替。

## 格式

```markdown
## [LRN-YYYYMMDD-XXX] category

**Priority**: low | medium | high | critical
**Status**: pending | resolved | promoted | promoted_to_skill
**Area**: research | infra | tools | docs | config

### 内容
简述：发生了什么、为什么错/不好、正确/更好的做法是什么。

### 建议修复
具体应该怎么改、改哪里。

### 元数据
- Source: error | correction | user_feedback | task_review | best_practice
- See Also: LRN-XXXXXXXX-XXX
- Pattern-Key: xxx
- Promoted-To:

---
```
